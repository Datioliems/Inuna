# Asset Boundary

Messenger/Abeto assets in `research/messenger-abeto-raw-assets-research-only/` are for private, non-commercial learning only.

Do not import those files into `game/`, commit them as game assets, publish them, sell them, or use them in public builds unless Abeto grants permission or a permissive license is found.

The game prototype must use original procedural assets, original Blender exports, or third-party assets with clear licenses.
