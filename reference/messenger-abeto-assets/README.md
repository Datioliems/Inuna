# Messenger Abeto Asset Reference

This folder is for learning and teardown only. It does not contain copied game assets.

## Why Raw Assets Are Not Copied

Messenger is free to play in a browser, but that does not mean its models, textures, sounds, code, or images are free to reuse. During this pass, no permissive asset license was found. Treat the assets as Abeto-owned unless the creators publish a license or grant permission.

## What Is Included

- `asset-manifest.reference-only.json`: observed public asset paths and technical signals collected from the live site and public JavaScript bundle.
- Source links for the site, scripts, and public preview image.
- A reference-only categorization of audio, visual, texture, model, and geometry paths.

## Safe Uses

- Study how assets are grouped: ambience, UI, dialogue, footsteps, water, vegetation, birds, quest feedback.
- Design an original asset list for the Vietnamese-dog healing game.
- Create our own Blender/Godot equivalents with different models, sounds, names, textures, and story content.
- Use the manifest as a checklist for what a polished tiny-world game needs.

## Do Not Use Without Permission

- Do not import Messenger's raw audio, textures, model files, image files, shaders, or code into our game.
- Do not publish a project containing Abeto assets.
- Do not copy character designs, map layout, logo/title style, or exact UI icons.

## Replacement Direction For Our Game

- Audio: record or source licensed ambience for village, river, forest, rain, insects, footsteps on dirt, footsteps in shallow water, soft dog vocal reactions.
- Models: create original Vietnamese native dog, animal NPCs, riverside houses, trees, footbridges, market props, boats, stones, and healing memory objects.
- Textures/materials: build a muted storybook toon palette with our own color atlas and Godot shaders.
- Nature systems: make original bird paths, water foam strips, cloud/noise masks, and light vegetation motion.
