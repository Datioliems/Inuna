# Inuna

Original cozy 3D game prototype about a stylized Vietnamese native dog exploring a gentle riverside world, helping animal NPCs, and restoring warmth through small healing quests.

## Current Slice

- Godot 4.7.x prototype in `game/`
- Third-person dog controller
- Tiny village/river/forest world
- Animal NPCs and first healing quest
- Toon storybook material shaders
- Audio zones, footsteps, birds, water, trees, and quest-state warmth

## Asset Boundary

Messenger/Abeto is used only as a learning reference. Raw downloaded research assets stay local under `research/` and are intentionally ignored by Git. Public game work must use original assets or properly licensed third-party assets.

## Start

Open `game/project.godot` with Godot 4.7.x.
