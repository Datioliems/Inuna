# Cho Ta Healing Game Prototype

Godot 4.7.x vertical slice for an original cozy game about a stylized Vietnamese native dog who helps a tiny riverside world heal.

## What Is Implemented

- Procedural Vietnamese-dog player blockout with toon material slots.
- Third-person follow camera behind the character.
- Tiny island/village/river/forest scene.
- Animal NPCs, including a first cat healing quest.
- Three memory pickups that complete the first healing quest.
- Runtime toon animal/world shaders plus outline and water shader.
- Ambience zones with smooth volume blending and procedural placeholder audio.
- Bird flock, animated water, swaying trees, and firefly-like memory accents.

## Controls

- Move: `WASD` or arrow keys
- Run: `Shift`
- Goal: collect 3 memories, then return to the cat

## Asset Boundary

This prototype does not import Messenger/Abeto raw assets. Research files under `../research/` are for private study only.
